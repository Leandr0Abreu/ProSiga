# ProSiga

## Sistema Acadêmico Inteligente

O ProSiga é uma plataforma acadêmica desenvolvida para simplificar a rotina de escolas, professores, alunos e famílias.

A proposta é centralizar informações importantes da vida escolar em um único ambiente, facilitando a comunicação, o acompanhamento acadêmico e a organização das atividades.

## Funcionalidades

- Acesso separado para professores e alunos.
- Cadastro de usuários conforme o perfil acadêmico.
- Organização de turmas e disciplinas.
- Acompanhamento de notas e frequência.
- Compartilhamento de avisos, tarefas e materiais.
- Comunicação entre escola, professores, alunos e responsáveis.
- Interface responsiva para computadores, tablets e celulares.
- Experiência visual simples, moderna e acessível.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- React Router
- CSS
- ESLint
